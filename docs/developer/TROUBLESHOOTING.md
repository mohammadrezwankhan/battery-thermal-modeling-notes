| Symptom | Source-based explanation | Action |
|---|---|---|
| `header must be exactly...` | Required first two columns and optional order are strict | Use the [CSV contract](API_CLI_AND_INTERFACES.md); omit unknown columns before importing, retaining original evidence separately |
| `time_s must equal the previous interval end` | Explicit-duration rows have a gap/overlap | Reconcile units and starts/durations; do not invent a final interval |
| Last interval extends beyond the last timestamp | Uniform CSV timestamps denote starts | Add `duration_s` when the final interval differs |
| `cannot be combined` | CLI supplies a constant for a quantity already scheduled by CSV | Choose one authoritative source; Python API schedule overrides differ from CLI behavior |
| Radiation rejected | Both emissivity and area must be enabled together; only RK4 supports radiation | Supply paired positive values and `--integration-method rk4` |
| Negative resistance or nonphysical temperature | The linear resistance relation or numerical trajectory left its admitted domain | Check parameter validity and a step/refinement study; exact integration does not fix invalid physics |
| Euler oscillates or overshoots | No stability controller is implemented | Compare with exact-linear when applicable and consult the derived timestep condition |
| Energy residual tiny but temperature inaccurate | Net interval heat is derived from computed temperature change | Compare an independent analytic case or reviewed refinement study |
| Limit `EXCEEDED` but exit code 0 | Limits are postprocessing summaries | Read assessment fields; CLI success means the computation completed |
| `--limit-report-csv` rejects a cold-only request | CSV writer covers upper limits only | Read lower assessments through the API or CLI; do not relabel an upper-limit file |
| `final_recovery_time_s` is empty | No exceedance occurred, or the trace ends above the upper limit | Interpret it together with `exceeded` and the terminal temperature |
| Portfolio notes disappear | Local storage depends on browser/profile/site context | Export the study plan before moving context; it is not stored in Git |
| New handbook differs from Markdown | Generated view is stale or Pandoc version changed | Run the renderer and `--check`, then review the derived diff |
